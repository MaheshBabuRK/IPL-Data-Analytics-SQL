# IPL Data Analytics – SQL Project

## Project Overview
This project focuses on analyzing Indian Premier League (IPL) cricket data using MySQL. It explores match and ball-by-ball delivery data to answer business questions and identify useful insights.

## Datasets
The project uses two datasets:

- **Matches_Data.csv** – Match-level information (1,095 rows and 20 columns).
- **Deliveries_Data.csv** – Ball-by-ball delivery information (260,920 rows and 17 columns).
